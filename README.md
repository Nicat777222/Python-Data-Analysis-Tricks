# Python-Data-Analysis-Tricks
"Data Analitikası (Python, Pandas, Matplotlib) üzrə öyrəndiyim qısa kodlar, fəndlər (tricks) və kiçik layihələr toplusu."
Bu layihəmizin əsas məqsədi "BlinkIT" adlı supermarket şəbəkəsinin satış məlumatlarını Python vasitəsilə analiz edərək arxada gizlənən biznes sirlərini üzə çıxarmaq və qərar qəbuledicilərə doğru istiqamət verməkdir. Üzərində işlədiyimiz data özündə fərqli məhsulların çəkisini, mağazada tutduğu sahəni, məhsulun növünü və ən əsası filialların açılış illərinə görə gətirdiyi satış rəqəmlərini birləşdirən çox zəngin bir məlumat bazasıdır və biz bu işə sadəcə kod yazmaq xatirinə yox, şirkətin gəlirlərini optimallaşdırmaq istəyən, tənqidi düşüncəyə sahib bir mütəxəssis gözü ilə yanaşmışıq.

Layihəyə ilk olaraq məlumatların təmizlənməsi prosesi ilə başladıq və cədvəldə məhsulların çəkisi sütununda olan mindən çox eksik xananı sadəcə silmək əvəzinə onları ümumi ortalama dəyərlə dolduraraq həm çox böyük məlumat itkisinin qarşısını aldıq, həm də gələcək maliyyə hesabatlarının dəqiqliyini qoruduq. Daha sonra biznes üçün ən vacib suallardan birinə cavab tapmaq məqsədilə Matplotlib kitabxanası ilə qrafiklər quraraq şirkətin əsas gəlir mənbəyinin məhz meyvə-tərəvəz və qəlyanaltı bölmələri olduğunu kəşf etdik. Bunun ardınca isə mağazalardakı bəzi marketinq miflərini çökdürmək üçün səpələnmə qrafiklərindən istifadə etdik və riyazi korrelyasiya vasitəsilə çox aydın şəkildə sübut etdik ki, məhsulun mağazada ən çox görünən yerdə olması və ya çəkisinin fərqli olması onun daha çox satılacağına və böyük gəlir gətirəcəyinə heç bir zəmanət vermir.

Analizimizin ən maraqlı və detektiv yanaşma tələb edən kəşfi isə zaman trendlərini, yəni filialların açılış illərinə görə performansını yoxlayarkən baş verdi. Belə ki, ilkin baxışda 2018-ci ilin gəlirlərinin digər illərə nisbətən fantastik dərəcədə yüksək görünməsinin əslində şirkətin o il aqressiv böyüməyə gedərək çox sayda filial açması ilə bağlı bir kənar dəyər (outlier) olduğunu üzə çıxardıq və dərhal datanı yenidən qruplaşdıraraq bir mağazaya düşən xalis orta satışı hesablayıb rəhbərliyə aldadıcı olmayan əsl həqiqəti göstərən yeni trend qrafikini təqdim etdik.
